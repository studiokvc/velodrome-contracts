# 2. Données et mécanismes

Velodrome combine AMM, votes escrow, gauges et émissions pour orienter la liquidité. Le parcours suit les pools, les veNFT, les votes, les récompenses et les mécanismes de frais. Ce chapitre isole le mécanisme correspondant dans les contrats et bibliothèques du dépôt : état conservé, appels, contrôles et invariant attendu. Les explications restent documentaires et ne constituent ni un audit ni une garantie de déploiement.
